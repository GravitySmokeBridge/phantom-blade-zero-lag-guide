## 🔍 Why Does Phantom Blade Zero Stutter?

The performance issues are usually caused by three things:

1. **Shader Compilation Stutter**
   Every time the game loads a new effect, enemy, or environment, it compiles shaders on the fly. If the cache is corrupted or the process is interrupted, it can cause massive stutters and extremely long load times.

2. **The Nvidia 621.01 Driver Issue**
   The latest Nvidia driver (621.01) has been reported to cause performance drops and instability in Phantom Blade Zero. If you updated your driver recently, this might be the reason your FPS dropped.

3. **Background Process Interference**
   Windows services and background apps compete with the game for CPU resources. When the game needs that CPU time to render a fast-paced combat sequence, it's not there.
